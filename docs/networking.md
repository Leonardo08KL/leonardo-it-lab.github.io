# Network Lab

Conceptos demostrados:

- IPv4
- TCP/IP
- Gateway
- DNS
- DHCP
- HTTP/HTTPS
- SSH
- Puertos TCP/UDP
- Diagnóstico

Herramientas documentadas:

```bash
ip addr
ip route
ping 192.168.1.1
ss -tulpn
dig example.com
nslookup example.com
curl -I https://example.com
traceroute example.com
```

Los resultados mostrados por el portafolio son demostrativos; no se permite ejecutar comandos arbitrarios del servidor desde el navegador.
